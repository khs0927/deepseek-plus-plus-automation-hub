# DeepSeek++ 세움터 자동화 및 한국건축규정 156개 룰 엔진 파이프라인

## 1. 개요 및 시스템 제약조건
본 모듈은 `khs0927/deepseek-plus-plus-automation-hub`를 건축 인허가 도메인에 특화하여, CAD/건축물대장 데이터를 세움터 웹 폼으로 직결하고 한국건축규정 156개 체크리스트를 2단계(Two-Tier)로 판정하는 파이프라인입니다.

### 핵심 시스템 제약사항
1. **설계자 프로필 영구 고정 주입**:
   - 사무소명: 건축사사무소 지음
   - 건축사: 이동희 건축사
   - 사업자번호: 604-08-99164
   - 본 프로필은 모든 생성 문서, 세움터 CDP 폼, 감리일지 및 보고서에 불변 상수로 강제 주입됩니다.
2. **세움터 제출 시 오류(빨간색 0건) 보장**:
   - 한국건축규정 156개 항목(건축물 107개 + 입지 49개)에 대하여 세움터 제출 시 부적합 0건을 달성합니다.
3. **토큰 소모 최소화 전략**:
   - 144개 고정 조항은 Tier 1 로컬 룰베이스로 자동 판정 (토큰 소모 0).
   - 12개 심층 조항(피난, 방화, 복합용도 등)만 Tier 2(DeepSeek + Graph/Vector RAG)로 정밀 처리.
