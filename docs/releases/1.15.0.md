## DeepSeek++ 1.15.0

1.15.0은 MCP 병렬 호출 안정화와 커스텀 확장 배포 일관성을 위한 유지보수 릴리스입니다.

### 주요 변화

- **MCP 병렬 호출 회귀 방지**: 서로 다른 도구 호출이 동시에 authorization reservation을 발급받아도 호출별 상태가 서로 덮어쓰이지 않는 테스트를 추가했습니다.
- **커스텀 확장 동기화**: 커스텀 확장 번들을 최신 Edge 빌드에서 재생성하도록 고정했습니다. 커스텀 번들은 이제 본체의 엄격한 request/session authorization 검증을 그대로 사용합니다.
- **세션 격리 유지**: 호출별 `requestId`, 브라우저 소유 채팅 세션, 문서 세션 검증을 수동 번들이 완화하지 못하도록 패키지 검증을 추가했습니다.
